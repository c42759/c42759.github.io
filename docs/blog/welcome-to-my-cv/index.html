Welcome to my interactive CV

January 15, 2026

Building an interactive CV is an interesting challenge.

Why an interactive CV?

Traditional resumes are static and often fail to convey the depth of a developer's experience. An interactive CV allows me to:

  • Showcase my skills in a real-world application.
  • Provide a more engaging experience for recruiters and engineering managers.
  • Experiment with new technologies like Next.js 16 and React Server Components.

Core Technologies

  1. Next.js App Router for dynamic routing.
  2. Tailwind CSS v4 for rapid and modern styling.
  3. Framer Motion for subtle micro-interactions.

Here is a snippet of my page.js component:

export default function Home() {
  return (
    <main className="flex flex-col items-center">
      <Header />
      <Timeline title="Professional Path" items={professionalPath} />
    </main>
  );
}
